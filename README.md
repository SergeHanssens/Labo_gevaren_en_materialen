# Labo: gevaren- en materiaalsymbolen — trainer

Oefentool om de gevarensymbolen (GHS/CLP-pictogrammen) en het labomateriaal te leren herkennen en benoemen.
Gemaakt voor de leerlingen OV4 Biotechnologische STEM-wetenschappen (BuSO). De benamingen en de uitleg
staan er exact in zoals in de cursusdocumenten van de klas.

**Online:** https://sergehanssens.github.io/Labo_gevaren_en_materialen/labo_symbols_trainer.html

## Wat zit erin

- Twee reeksen: **gevarensymbolen** (9) en **materialen** (42).
- Oefenvormen:
  - flashcards;
  - meerkeuze in zes richtingen (symbool ↔ benaming ↔ uitleg);
  - combinatie-oefeningen (tekst–tekst en afbeelding–tekst);
  - invulvraag met woordvoorspeller (symbool → benaming).
- Score per oefenvorm en reeks, lokaal bewaard in de browser. Er worden geen gegevens verstuurd.

## Zelf gebruiken

Open `labo_symbols_trainer.html` in een browser. De afbeeldingen worden geladen vanaf GitHub Pages,
dus een internetverbinding is nodig. Wie een eigen reeks wil maken: de lijsten `DATA_GEVAREN` en
`DATA_MATERIALEN` staan bovenaan in het script; per item een afbeelding, een benaming en een uitleg.
